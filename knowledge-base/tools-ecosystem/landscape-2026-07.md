## Append: 2026-07-06 landscape monitor update

*Added by the 2026-07-06 monitor run (window: 2026-06-29 → 2026-07-06). No flagship platform GA this cycle. The one skill change is a restrained version bump — `sales/agentic-commerce-readiness` v2.5 → v2.6 — that discharges the consumer-control sub-check the 2026-06-29 KB entry explicitly scheduled for "next cycle."*

**§3 governance / consumer-trust controls — consumer-control sub-check discharged (ACT: `agentic-commerce-readiness` v2.5 → v2.6).** The 2026-06-29 KB entry logged a named candidate sub-check from the Checkout.com *Agentic Commerce 2026* study and deferred it one cycle (restraint: no new-skill + version-bump in the same run). This window carried no new-skill event, so the deferred item was built. The study's finding held up under fresh trade analysis this week (Retail-Insider, InternetRetailing, and Digital Applied's "Agentic Checkout Trust Gap" breakdown all re-reported the same three consumer non-negotiables — spending caps ~30%, instant permission revocation ~29%, easy cancellation ~28% — plus the consumer delegated-spend comfort (~£177) sitting *below* the merchant-assumed (~£200) figure and ~75% of merchants calling real-time revocation critical to adoption). The v2.6 sub-check (step 3) audits whether the merchant *surfaces and honors* the three levers — cap enforcement as a hard stop, revocation honored *between cart-build and settlement* (not only at token issuance), and agent-placed-order cancellation inside the normal window without a portal hop — and adds a calibration check: the merchant's `assumed_autonomous_spend_threshold` (per-order step-up ceiling) should be tuned to the *consumer's* lower comfort figure, not the higher merchant-assumed number. This is deliberately distinct from the *cryptographic* scope binding already graded on the AP2 Intent Mandate / Mastercard Verifiable Intent rails — those encode the ceiling in the token; the v2.6 check is the merchant-side surfacing/revocation/cancellation UX-and-operations obligation.

**§4 AEO/GEO tooling — tracker-vendor cluster keeps expanding (CONTEXT — vendor-list grounding for step 10).** Three more named generative-engine-optimization / answer-engine-optimization vendors surfaced in one week: **CiteLens** (runs a brand's customer questions across multiple AI engines, captures the cited source pages, and reports an AI-visibility score, competitive share, and sentiment); **Contentful Palmata** (helps a brand understand, measure, and improve how AI answer engines represent it); and **Nudge** (a $1.1M pre-seed agentic-commerce platform spanning "visibility, shoppable funnels, and catalog enrichment" — the visibility layer is a GEO play, the catalog-enrichment layer is agent-readability). These join the already-named tracker set (Profound, Peec, AIclicks, Hall, Gauge, Adobe Brand Visibility + Semrush) for `agentic-commerce-readiness` step 10's AEO/GEO tracker-KPI list. No workflow change — the category is now crowded enough that the skill grades the *presence of a tracker and its KPI wiring*, not any single vendor. Novelty low (named category), relevance moderate.

**§6 retail media on agentic surfaces — Albertsons Media Collective × Criteo conversational search (CONTEXT — adjacent to `agentic-retail-media-mediation`).** Albertsons' retail-media arm integrated with Criteo to bring sponsored-product discovery into Albertsons' AI-powered conversational search, so eligible sponsored products can appear in conversational carousels. This is a concrete instance of the sponsored-placement-on-agent-surface pattern that `agentic-retail-media-mediation` already owns; single retailer + single ad-tech vendor, no new gate met. Watch: a second named retailer-media-network running sponsored placement inside an *agent/conversational* surface (vs. a traditional on-site search result) would be worth a sub-check on how the mediation skill reconciles organic agent ranking with sponsored injection.
